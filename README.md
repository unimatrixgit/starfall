# Starfall Command

A browser-based sci-fi strategy game and local practice universe.

## Run locally

Serve the `dist/` directory with any static web server and open its `index.html`. The game stores practice-round state in the browser.

## Live practice build

https://starfall-command.bonnystoat9.chatgpt.site/

## Source layout

- `dist/index.html` — game interface and theme styles
- `dist/game.js` — game systems and local state simulation
- `dist/assets/` — interface, race, ship, and structure artwork
